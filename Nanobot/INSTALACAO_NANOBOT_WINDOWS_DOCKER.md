# Nanobot no Windows com Docker Desktop

Guia testado para executar o **HKUDS/nanobot** no Windows usando **PowerShell 7**, **Docker Desktop**, **Ollama Cloud com `gemma4:cloud`** e **MiniMax**.

> Este guia não usa modelos locais. O Ollama funciona como cliente para um modelo hospedado na nuvem.

## Pré-requisitos

- Windows 10 ou Windows 11
- PowerShell 7
- Docker Desktop em
